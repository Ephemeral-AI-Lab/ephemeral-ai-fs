## Counter checks that must not be blurred

- Native FULL/PREFIX encode **calls** include failed optional compressor attempts; successfully produced frame **counts/bytes** are separate. A failed mandatory FULL preparation invalidates that run. Do not divide successful byte totals by all calls without the correct denominator.
- For the proven unique native eligible cohort, native FULL winners + PREFIX winners + race-selected-existing must conserve counts and canonical bytes against eligibility. If proof fails, retain attempt populations but do not publish a unique-winner table as authenticated.
- Native fallback outcomes and prepared alternatives are pre-admission work. A/B alternatives can lose admission races; winner counts are not their denominator. Old generic full_alternative_bytes/mixed_alternative_bytes remain legacy-only, while aggregate selected_encoded_bytes may include both lanes. No cross-population durable savings claim.
- Native depth histograms count completed reconstructions, not distinct stored objects or all files read. native_raw_decoded_bytes includes bases and repeated reconstruction; canonical selected bytes count each unique object once. Frame request/parser bytes are logical requested ranges, not disk-page I/O. Physical per-action deltas can include asynchronous read-ahead crossing the interval.
- A final pre-verification inventory plus authoritative pack intervals and validated logical first-retained prefixes may establish admission checkpoint; pack ID order alone cannot. Final B-tree placement cannot reconstruct historical fragmentation.
