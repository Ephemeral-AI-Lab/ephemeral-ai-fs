# Experiment 1 protocol — fixed before encoding

Scope: original retained-candidate Store, eleven namespace roots, read-only SQLite; no public save/history replay, Docker, product edits, Store writes, or product benchmark. Results are diagnostic counterfactual metadata encoding and standalone full-hash locator projections, never an achieved complete-Store allocation. Source must match post-verification SHA256713e43e4f31a489c8eb347b953702ca97c33b17832fbdc0633018584308507f4 before and after.

Exactly three treatments; no parameter sweep or post-result tuning:

1. A — reconstructed current metadata. Decode all original46,288 metadata objects including283 legacy deltas; reconstruct and authenticate exact canonical IDs. Retain original metadata inventory, table partitions, wrappers and namespace roots.
2. B — inline inode values. Retain full32-byte stable inode IDs. Replace each inode-table leaf entry's32-byte inode-record ID with its exact73-byte semantic inode value(kind1/refcount8/content-root32/metadata-root32). Remove separate inode-record and old table/root objects. Rebuild each of11 inode tables from sorted exact original pairs, using maximal bounded leaves of77 entries and balanced deterministic partition(counts differ at most1; minimum occupancy half-full except root). Branch capacity127. New inline leaf magic LFS5INT, role7, original31-byte summary framing, canonical LFSO envelope. Internal nodes use same new magic and existing64-byte key/child entries, subtree byte summary=count*105. New profile is BLAKE3 of a diagnostic format descriptor; new namespace magic LFS5FSR and root points to rehashed new table. Unchanged metadata objects remain byte-for-byte. No content IDs shortened.
3. C — B plus direct directory mappings. Remove all4,008 directory-state wrappers; rewrite each directory inode's content root from wrapper ID to its existing mapping-root ID. Derive/verify directory level/count from the authenticated mapping node. Use distinct format descriptor/profile from B. All other rules identical.

All replacement canonical tree pages <=8192B; roots/object IDs actual full BLAKE3 hashes. Every retained inode value must decode to exact original inode ID/kind/refcount/content/metadata; C translates its directory content root back to original wrapper semantics during comparison. Verify directory mappings and summaries for all states. Focused synthetic hardlink+rename oracle reuses one stable inode across two names, changes namespace only, checks linkcount2 and identity remain; this supplements the original workload with linkcount coverage.

Pinned legacy metadata Zstandard policy: `ZSTD_getCParams(1,raw_size,0)`, clamp windowLog to16, static context estimated from those CParams bounded to1MiB, setCParams/setFParams(contentSize1,checksum1,noDictID1), compress2. Before treatment measurements require byte-for-byte recreation of every original decoded metadata group's codec selection and stored encoded bytes (compress only if at least16B smaller). Record loaded library path/version/hash. Using a system library default or only verifying decompression is insufficient.

Matched packing for all three: complete unique metadata inventories, deterministic role-magic then full-ID order; FULL record grammar only, <=16KiB decoded groups, current count/offset directory, RAW versus pinned Zstd16B threshold; pack sequentially with <=256KiB physical AND decoded pack bytes (matching pack::assemble), <=256 groups, <=8191 records. Account real group/pack headers. This offline inventory policy is deliberately identical across alternatives. It excludes existing metadata deltas and online admission order; A is a within-experiment control, not a recreation of measured6,550,582B metadata. Stored original selected groups are separately validated and reported. Do not subtract A/B/C pack deltas directly from49,319,936B as a product allocation forecast.

Index projection: for each treatment retain actual original content-object IDs/canonical lengths/physical locators, substitute actual new metadata IDs/canonical lengths/diagnostic pack locators with pack numbers beyond original maximum. Create isolated SQLite4096-byte STRICT WITHOUT ROWID objects table with current constraints; insert in sorted full-ID order, VACUUM, use dbstat object-tree bytes. Include exact inventory rows and all rehashed replacement tree/root rows. No source Store copy/mutation. Report metadata pack bytes plus index bytes as matched diagnostic subtotal; residual Store tables/WAL/allocation/concurrency/Commit latency are unmeasured.

Stop after all3 treatments, exact semantic comparisons, codec equivalence, source integrity, script self-checks, inventory/index accounting and report. If any gate fails, record failure and fix a diagnostic implementation defect; do not alter the three treatments or codec policy to improve their byte result.
